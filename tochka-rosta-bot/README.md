# Точка роста

Учебный Telegram-бот для абитуриентов ВШЭ — Нижний Новгород. Бот принимает баллы по русскому языку, профильной математике и информатике, сравнивает их с данными выбранных программ и показывает ориентир поступления.

## Возможности

- ввод трёх результатов ЕГЭ;
- проверка минимальных баллов;
- сравнение с проходными баллами 2025 года;
- несколько вариантов программ;
- сценарий «если улучшить баллы»;
- удаление введённых данных командой `/delete`.

Данные о программах находятся прямо в `bot.py`. Перед использованием в следующем году их нужно обновить по официальным источникам ВШЭ.

## Запуск на Mac

Нужен Python 3.10 или новее.

1. Открой папку проекта в VS Code.
2. Открой терминал и создай виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Установи библиотеку:

```bash
python3 -m pip install -r requirements.txt
```

4. Скопируй `.env.example` в `.env` и вставь токен. Файл `.env` нельзя загружать на GitHub.
5. Запусти бота:

```bash
python3 bot.py
```

Бот работает, пока запущена команда и компьютер подключён к интернету.

## Загрузка на GitHub через сайт

1. Создай пустой репозиторий на GitHub, например `tochka-rosta-bot`.
2. Открой репозиторий и нажми **Add file → Upload files**.
3. Перетащи содержимое этой папки: `bot.py`, `requirements.txt`, `README.md`, `.gitignore` и `.env.example`.
4. Проверь, что файла `.env` среди загружаемых файлов нет.
5. Нажми **Commit changes**.

GitHub хранит код, но не запускает бота. Для учебной сдачи или показа репозитория этого достаточно.

## Источники данных

- Проходные баллы: https://nnov.hse.ru/bacnn/statist
- Минимальные баллы: https://nnov.hse.ru/bacnn/minpoints
- Информация абитуриентам: https://nnov.hse.ru/bacnn/information

Прошлогодний проходной балл является ориентиром и не гарантирует поступление.
